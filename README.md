# Indian Zipp House — Multi-page website

A free, static 9-page website suitable for GitHub Pages.

## Pages
- `index.html` — Home
- `collections.html` — All collections
- `nylon.html`, `metal.html`, `plastic.html`, `invisible.html`, `waterproof.html` — Individual collection pages
- `about.html` — About
- `contact.html` — Enquiry form

## Important before publishing
1. Open `script.js` and replace `YOUR_EMAIL@example.com` with your actual business email. The contact form uses `mailto:` and **does not** store submissions or send them automatically. The visitor must send the email in their email app.
2. Replace illustrative product SVGs in `assets/` with real photographs when available. No product specifications, certifications, or company claims have been invented.
3. Review all text for accuracy and add business contact information.

## Publish free on GitHub Pages
1. Create a free account at https://github.com/signup
2. Create a **public** repository named `indian-zipp-house`.
3. Upload the **contents** of this folder to the repository root (not the ZIP itself). Ensure `index.html` is in the root.
4. Open repository Settings → Pages → Build and deployment → Deploy from a branch → `main` → `/(root)` → Save.
5. Wait for the GitHub Pages deployment. It will appear at `https://USERNAME.github.io/indian-zipp-house/`.
6. Once live, in Settings → Pages, set custom domain `www.indianzipphouse.com`.
7. At Squarespace Domains DNS, add a `CNAME` record for host `www` pointing to `USERNAME.github.io` (replace USERNAME). Do not delete existing email-related DNS records. Check GitHub Pages documentation for apex domain and HTTPS setup. DNS changes can take time to propagate.

No build step or paid hosting is required. Google Fonts requires an internet connection; system fallback fonts will be used otherwise.
